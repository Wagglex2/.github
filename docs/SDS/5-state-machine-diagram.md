## 5. State machine diagram

<img width="1486" height="2159" alt="Image" src="https://github.com/user-attachments/assets/07577cf2-93bb-412d-bbc0-b6236b9e67a3" />

 위 State machine diagram은 사용자가 서비스에 접속한 시점부터 로그아웃에 이르기까지의 전체 흐름을 상태 기반으로 표현한 것이다. 

<br>

시작은 [비인증] 상태에서 하며, 로그인 또는 회원가입을 통해 [인증됨] 상태로 전환된다. 이후 사용자 유형(최초 로그인 여부)에 따라 [기본정보입력] 또는 [서비스이용] 상태로 이동한다. [서비스이용] 상태에서는 공고 열람, 공고 작성, 개인정보 관리, 지원 공고 관리, 올린 공고 관리, 팀 관리, 알림 관리 등 다양한 기능을 사용할 수 있다.

<br>

먼저 [비인증] 상태에서는 사용자가 로그인 또는 회원가입을 시도할 수 있다. 로그인 시도 시 [인증] 상태로 이동하며, 로그인 성공 시 [인증됨] 상태로 전환된다. 실패 시 다시 [대기] 상태로 돌아간다. 회원가입을 시작하면 [가입] 상태로 이동하고, 가입을 완료하면 [인증됨] 상태가 된다. 취소할 경우 다시 [대기] 상태로 돌아간다.

<br>

[인증됨] 상태가 되면 우선 사용자의 유형을 판단하기 위한 [사용자상태확인] 상태로 이동한다. 최초 로그인 사용자는 [기본정보입력] 상태로 전환되며, 기본 정보 입력 시 [서비스이용] 상태로 전환된다. 기존 사용자는 바로 [서비스이용] 상태로 이동한다. 또한 [인증됨] 상태에서는 항상 로그아웃이 가능하며, 로그아웃 시 다시 [비인증] 상태로 전환된다.

<br>

[서비스이용] 상태는 전체 기능의 중심이 되는 상태로, 기본적으로 [공고열람] 상태에서 시작한다. [공고열람]에서는 공고 목록을 조회할 수 있고, 공고를 선택하면 [상세보기] 상태로 이동한다. 상세 페이지에서는 지원하기를 통해 [지원작성] 상태로 이동할 수 있으며, 지원 제출을 완료하면 다시 [상세보기] 상태로 복귀한다.

<br>

공고 등록 기능을 선택하면 [공고작성] 상태로 이동하며, 공고 작성이 완료되면 [작성완료] 상태로 전환된다. 작성 완료 후에는 다시 [공고열람] 상태로 전환된다. 

<br>

마이페이지에서 프로필 관련 기능을 선택할 경우 [개인정보관리] 상태로 전환되며, 이 안에서 [정보조회], [정보수정], [비밀번호변경]과 같은 세부 기능을 수행할 수 있다. 작업 완료 시 다시 [정보조회] 상태로 돌아온다.

<br>

지원한 공고와 관련된 기능은 [지원관리] 상태에서 사용할 수 있다. [지원목록]에서 지원 취소를 진행하면 [지원취소] 상태로 이동하며, 취소 완료 후 다시 [지원목록]으로 돌아간다. 

<br>

사용자가 등록한 공고는 [올린공고관리] 상태에서 관리되며, 공고 수정 시 [공고수정] 상태로 전환되고 저장 후 [공고열람.상세보기] 상태가 된다. 공고 삭제 시 [공고삭제] 상태로 전환되고 삭제 후 목록으로 돌아간다. 또한 지원자를 조회하는 경우 [지원자관리] 내부의 [지원자목록]과 [지원검토] 상태를 오가며, 처리 완료 후 목록으로 돌아간다.

<br>

[팀관리] 상태에서는 리뷰 작성/수정/삭제가 가능한 [리뷰관리] 상태와, 팀원을 삭제(리더만 가능)하는 [팀원삭제] 상태로 이동할 수 있다. 각 상태의 작업이 완료되면 다시 [팀원목록] 상태로 복귀한다.

<br>

알림 기능은 [알림관리] 상태에서 이루어진다. 기본적으로 [알림조회] 상태에서 시작하며 알림 삭제 시 [알림처리] 상태로 이동하고 삭제 완료 후 다시 [알림조회] 상태로 돌아간다.

<br>

서비스 이용 과정 전반에서 사용자가 로그아웃을 선택하면 즉시 [비인증] 상태로 전환되며, 이를 통해 전체 상태 흐름이 초기 상태로 돌아간다.
